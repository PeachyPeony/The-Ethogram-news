# The Ethogram 
## Project Overview
**The Ethogram is a responsive one-page news website dedicated to fascinating
research and discoveries in the field of ethology - the scientific study of animal behavior. Visitors can explore featured articles, browse additional news stories, learn about the purpose of the website and connect through social media links.** 

# Purpose

The goal of this project was to practice frontend development skills by creating a responsive webpage using only HTML and CSS. 

Throughout the project i focused on: 

- Writing semantic HTML 
- Structuring content clearly
- Building responsive layouts
- Using Flexbox for positioning
- Creating reusable styling
- Improving accessibility through alt text and descritive links
- Organizing CSS for readability and maintainability
