# The Ethogram 
## Project Overview
**The Ethogram is a responsive one-page news website dedicated to fascinating
research and discoveries in the field of ethology - the scientific study of animal behavior. Visitors can explore featured articles, browse additional news stories, learn about the purpose of the website and connect through social media links.** 

# Purpose

The goal of this project was to practice frontend development skills by creating a responsive webpage using only HTML and CSS. 

Throughout the project i focused on: 

- Writing semantic HTML 
- Structuring content clearly
- Building responsive layouts
- Using Flexbox for positioning
- Creating reusable styling
- Improving accessibility through alt text and descritive links
- Organizing CSS for readability and maintainability 

# Design 

## Color palette

The website uses soft greens with black text to create a calm and natural aesthetic inspired by wildlife.

Primary color include: 
- Alabaster Grey (#D7D5DA)
- Turquoise (#55D6BE)
- Aquamarine (#ACFCD9)
- Black (#0B070D) 

These colors were chosen to create good contrast while reflecting themes of nature. 

## Typography

Two Google Fonts are used throughout the project. 

**Calligraffitti** 

Used for: 
- Navigation
- Main heading 

This font gives the website a distinguished identity. 

**Nunito**

Used for: 
- Body text
- News articles
- General content

Nunito improves readability while keeping the overall design clean.

## Images 

The project uses animal photographs to support the news articles.
Images include: 
- Dolphins
- Wolves
- White-necked Jacobin hummingbird
- Orcas
- Kangaroos

All images include descriptive alternative text to improve accessibility.
